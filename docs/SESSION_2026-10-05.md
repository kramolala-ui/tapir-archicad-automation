# Сессия 2026-10-05 — RotateElementsByAngle для Tapir (форк kramolala-ui)

## Задача и результат

Исходная задача: нужен «поворот библиотечного элемента в Archicad на угол
вокруг центра» через JSON API. Встроенный `SetDetailsOfElements` не умеет
менять `angle` для библиотечных элементов (радиаторов, дверей, любых Object).
GDL-параметра поворота у них нет. Официальный API бессилен.

Решение: своя C++ команда `RotateElementsByAngle` в форк Tapir'а. Работает,
проверена на живом Archicad 26. Точность до 6 знака после запятой.

## API команды

JSON-запрос:
```
{
  "command": "API.ExecuteAddOnCommand",
  "parameters": {
    "addOnCommandId": {
      "commandNamespace": "TapirCommand",
      "commandName": "RotateElementsByAngle"
    },
    "addOnCommandParameters": {
      "elementsWithRotations": [
        {"elementId": {"guid": "..."}, "rotationAngle": 1.5707963267948966},
        {"elementId": {"guid": "..."}, "rotationAngle": -0.523599,
         "rotationCenter": {"x": 100, "y": 200}},
        {"elementId": {"guid": "..."}, "rotationAngle": 0.785398, "withCopy": true}
      ]
    }
  }
}
```

Параметры каждого элемента:
- elementId — {guid}, обязателен
- rotationAngle — число в радианах, против часовой, обязателен
- rotationCenter — {x, y}, опционально. Если не задан — AABB-центр.
- withCopy — bool, опционально. Копия поворачивается, оригинал на месте.

Из Python (через TapirConnection):
```python
tapir.run_command('RotateElementsByAngle', {
    'elementsWithRotations': [
        {'elementId': {'guid': '...'}, 'rotationAngle': 1.5707963267948966}
    ]
})
```

## Грабли сборки (не повторять)

Причина всех ошибок: код писался под апрельский Tapir (1.6.x), база обновилась
до 1.7.1. Что ломалось:

1. `GetResponseSchema` в CommandBase стал `final`. Надо переопределять
   `GetRawResponseSchema` (сигнатура та же: GS::Optional<GS::UniString>).

2. Хвост старого имени класса в конструкторе: скрипт переименования заменил
   первое вхождение, но осталась строка
   `RotateElementsByAngleCommand::RotateElementsCommand ()`. Компилятор ругался
   C4430 и C2550. Фикс — заменить второй хвост.

3. Коллизия с upstream: у Tapir'а уже есть `RotateElementsCommand` (поворот по
   дуге через beginPoint/endPoint/origin). Их команда осталась, наша названа
   `RotateElementsByAngleCommand`, имя команды `RotateElementsByAngle`. Обе
   сосуществуют без конфликта.

## Работа с GitHub через AI Bridge

Канал `github://...@branch/path` в AI Bridge поддерживает:
- action=request — чтение файла из ветки
- action=read — срез файла (mode=head|tail|slice)
- action=stat — метаданные
- op=write/replace в ===AI_CHANGES===

Канал НЕ поддерживает:
- action=list — возвращает файлы локальной карты AI Bridge, не GitHub
- action=search — ищет только в локальной карте, не в GitHub (scanned_files: 0)
- op=delete — не поддержан

ВНИМАНИЕ: запись через ===AI_CHANGES=== в github:// идёт в ветку с датой
(backup/work_YYYYMMDD), а не в указанную @branch. Отчёт "applied=N, failed=0"
не означает, что запись в GitHub прошла. Проверять SHA блоба через API.

Прямая запись через GitHub Contents API (минуя AI_CHANGES):
```python
from agent_tools.github_service import GitHubService
svc = GitHubService(project_root='.')
svc.write_file(
    repo='kramolala-ui/tapir-archicad-automation',
    path='archicad-addon/Sources/AddOnMain.cpp',
    content=new_content,
    branch='fresh',
    message='commit message',
    create_branch_if_missing=False,
    make_backup=False,
)
```
Так пишем точно в нужную ветку.

CDN: raw.githubusercontent.com кэширует на 5 минут. api.github.com/repos/.../contents/...
не кэшируется, отдаёт свежий blob. Для проверок — использовать api.github.com.
SHA блоба — отпечаток содержимого, если не изменился — запись не прошла.

## GitHubService — публичный API

Методы (см. agent_tools/github_service.py):
- has_token() -> bool
- get_token() -> str
- set_token(t), clear_token()
- get_repo() -> 'owner/repo[@ref]'
- set_repo(r), clear_repo()
- get_donor_github(), set_donor_github(r), clear_donor_github()
- is_configured() -> bool
- fetch_file(repo, path, ref) -> str
- write_file(repo, path, content, branch, message, create_branch_if_missing, make_backup) -> dict
- fetch_tree(repo, ref) -> dict
- list_files(repo, subdir, ref) -> list[str]
- cache_info(), clear_cache()
- build_pr_url(repo, base_ref) -> str

Токен хранится в QSettings (реестр Windows), между прогонами не сбрасывается.
Ключи: github/token, github/repo, donor_github.

## Про кнопку Update в Tapir

Tapir умеет проверять обновления у upstream (VersionChecker). Кнопка
Update Add-On в меню Options → Tapir скачивает ИХ .apx и заменяет наш.
Наша команда RotateElementsByAngle пропадёт.

Правило: не кликать Update Add-On, пока не готов пересобрать свой .apx
с новым upstream. Опционально — отключить проверку обновлений правкой
VersionChecker.cpp (IsUsingLatestVersion() всегда return true).
